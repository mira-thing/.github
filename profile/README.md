<h1 align="center">Mira</h1>

<p align="center">Fully standalone, fully free and fully open source custom firmware for the discontinued Spotify Car Thing.</p>

## Key Features
- Fully on device voice controls
- Karaoke lyrics
- Album art/lyrics view
- Gesture controls
- Podcast support 
- Full physical controls
- Save the current song to Liked Songs
- Customizable Settings
- **Much more!**

## Get it
Grab a build from [mira-releases](https://github.com/mira-thing/mira-releases) and flash with the standard Car Thing tools.
